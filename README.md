# poopoint · поддержка и приватность

Публичные русские и английские страницы iPhone-приложения «Я здесь какал» / poopoint.

- [Поддержка](https://ubcent.github.io/poopoint-site/)
- [Политика приватности](https://ubcent.github.io/poopoint-site/privacy.html)
- [English support](https://ubcent.github.io/poopoint-site/en/index.html)
- [English privacy policy](https://ubcent.github.io/poopoint-site/en/privacy.html)

Политика от 7 октября 2026 года описывает версии приложения 1.0 и 1.1. Открытки и повторные посещения доступны при использовании 1.1; в более ранней 1.0 этих функций нет. Публикация страниц поддержки и политики не подтверждает выпуск обновления приложения в App Store.

HTML/CSS без скриптов, аналитики и внешних зависимостей. Исходный код приложения хранится отдельно в приватном репозитории; этот репозиторий содержит только сайт.

GitHub Pages публикует ветку `main`, каталог `/`. После изменения HTML или CSS обычный push запускает обновление страниц. `.nojekyll` отключает обработку Jekyll.
