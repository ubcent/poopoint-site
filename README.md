# poopoint · поддержка и приватность

Публичные страницы iPhone-приложения «Я здесь какал».

- Поддержка: https://ubcent.github.io/poopoint-site/
- Политика приватности: https://ubcent.github.io/poopoint-site/privacy.html

HTML/CSS без скриптов, аналитики и внешних зависимостей. Исходный код приложения хранится отдельно в приватном репозитории; этот репозиторий содержит только сайт.

GitHub Pages публикует ветку `main`, каталог `/`. После изменения HTML или CSS обычный push запускает обновление страниц. `.nojekyll` отключает обработку Jekyll.

Контакт поддержки: Dmitry Bondarchuk, dvbondarchuk@gmail.com.
